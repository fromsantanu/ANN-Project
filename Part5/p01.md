## **Chapter 20: Student Exercises**

---

### **1. Why Exercises Matter**

Understanding theory is important, but real learning happens when you **try things yourself**.

👉 These exercises will help you:

* Think independently
* Experiment with ideas
* Build confidence

---

### **2. Exercise 1: Modify the Dataset**

Try changing the dataset and observe what happens.

#### **Ideas to Try**

* Add more rows (more patients)
* Change values (increase BP, sugar, etc.)
* Add a new feature (e.g., heart rate)

Example:

```id="e2k7md"
[55, 150, 110, 78, 220] → ?
```

👉 Ask yourself:

* Does prediction change?
* Does model become better with more data?

---

### **3. Exercise 2: Change Output Patterns**

Try modifying labels:

* Change some 0 → 1 or 1 → 0
* Introduce slight variations

👉 Observe:

* Does the model get confused?
* Does loss increase?

---

### **4. Exercise 3: Change Model Architecture**

Modify the number of neurons:

* Hidden layer: 4 neurons
* Hidden layer: 16 neurons

Or even try:

```id="p4m8xn"
Input → Hidden1 → Hidden2 → Output
```

👉 Observe:

* Does accuracy improve?
* Does training become slower?

---

### **5. Exercise 4: Change Learning Rate**

Try different values:

```id="t9k2qb"
lr = 0.1
lr = 0.01
lr = 0.001
```

👉 Observe:

* Too fast?
* Too slow?
* Stable learning?

---

### **6. Exercise 5: Change Activation Function (Advanced)**

Instead of sigmoid in hidden layer, try:

* ReLU (later concept)

👉 Observe how learning changes

---

### **7. Exercise 6: Track Loss**

Print loss for each epoch:

👉 Check:

* Is it decreasing?
* Is it fluctuating?

---

### **8. Mini Challenge**

Try to answer:

👉 “What combination gives the best performance?”

* Best neurons
* Best learning rate
* Best dataset

---

### **9. Real-Life Analogy**

Think like a scientist:

* Change one thing
* Observe results
* Learn from experiment

👉 This is how real AI models are developed

---

### **10. Important Advice**

* Do not try everything at once
* Change one parameter at a time

👉 This helps you understand cause and effect

---

### **🎯 Key Idea of This Chapter**

👉 **Learning improves through experimentation**
