## **Chapter 3: What is a Neuron?**

---

### **1. A Neuron = A Simple Calculator**

Now we move one step closer to building our neural network.

👉 A **neuron** is nothing but a **small calculator**.

It takes inputs, does some calculation, and gives an output.

---

### **2. How Does This Calculator Work?**

The neuron:

1. Takes multiple inputs
2. Multiplies each input with a number (called weight)
3. Adds everything together
4. Adds one extra value (called bias)

👉 Then gives the final result

---

### **3. Core Idea (Mathematical Form)**

This is how a neuron works mathematically:

y = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b

---

### **4. What Do These Symbols Mean?**

Let’s translate this into simple language:

* (x_1, x_2, x_3...) → Inputs (Age, BP, Sugar, etc.)
* (w_1, w_2, w_3...) → Importance of each input
* (b) → Extra adjustment (bias)
* (y) → Final output

👉 Think of **weights as importance levels**

Example:

* BP might be more important than weight
* Sugar might be very important

---

### **5. Simple Numerical Example**

Let’s take a very small case with just 2 inputs:

* (x_1 = 50) (Age)
* (x_2 = 140) (BP)

Weights:

* (w_1 = 0.2)
* (w_2 = 0.5)

Bias:

* (b = 10)

---

Now calculation:

[
y = (0.2 \times 50) + (0.5 \times 140) + 10
]

Step-by-step:

* (0.2 \times 50 = 10)
* (0.5 \times 140 = 70)

So,

[
y = 10 + 70 + 10 = 90
]

👉 Final output = **90**

---

### **6. Understanding This Intuitively**

Think of it like a score:

* Each input contributes something
* Important inputs contribute more
* Everything is added together

👉 The neuron is simply **combining inputs into one number**

---

### **7. Why Is This Important?**

This small calculator (neuron) is the **basic building block** of:

* Neural Networks
* Deep Learning models

Many neurons together = powerful system

---

### **🎯 Key Outcome of This Chapter**

You should now understand:

* A neuron is just a **mathematical calculator**
* It combines inputs using weights and bias
* It produces a single output
