## **Chapter 17: Making Predictions**

---

### **1. What Happens After Training?**

After training, the model has learned patterns.

Now we ask:

👉 *“Can it predict for a new patient?”*

This step is called:

👉 **Making Predictions (Inference)**

---

### **2. Important Idea**

During prediction:

* No learning happens
* No weight updates

👉 We only **use the model**, not train it

---

### **3. New Data Example**

Suppose a new patient comes:

* Age = 55
* BP = 145
* Sugar = 110
* Weight = 78
* Cholesterol = 220

👉 This data was **not seen during training**

---

### **4. Converting Data for PyTorch**

We need to convert input into a tensor:

```python id="x7k2pd"
import torch

new_data = torch.tensor([[55, 145, 110, 78, 220]], dtype=torch.float32)
```

👉 Notice the double brackets `[[...]]`
This means **one sample with multiple features**

---

### **5. Making the Prediction**

```python id="m4z8qy"
model.eval()   # Set model to evaluation mode

with torch.no_grad():
    prediction = model(new_data)
```

---

### **6. Understanding This Code**

* `model.eval()`
  👉 Tells PyTorch we are testing, not training

* `torch.no_grad()`
  👉 Saves memory, no gradient calculation

---

### **7. Output Interpretation**

Example output:

```python id="u9n3xs"
tensor([[0.82]])
```

👉 This means:

* **82% probability of risk**

---

### **8. Converting to Final Decision**

We can convert probability into 0 or 1:

```python id="p3k9wd"
result = (prediction > 0.5).float()
```

* > 0.5 → 1 (Risk)
* ≤ 0.5 → 0 (No Risk)

---

### **9. Real-Life Analogy**

Think of an exam:

* Training → studying
* Prediction → giving exam

👉 In exam, you don’t learn — you apply what you learned

---

### **10. Important Insight**

* Model performance depends on training quality
* Good training → reliable predictions

---

### **🎯 Key Idea of This Chapter**

👉 **Prediction = using trained model on new data**
