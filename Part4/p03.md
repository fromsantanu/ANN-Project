## **Chapter 19: Improving the Model**

---

### **1. Can We Make the Model Better?**

Yes — and this is where real learning begins.

After training, you may notice:

* Predictions are not very accurate
* Loss is not decreasing well

👉 So we ask:

**“How can we improve the model?”**

---

### **2. Key Idea**

👉 A model is **not fixed**

We can adjust different parts to improve performance.

This process is called:

👉 **Tuning (or improving) the model**

---

### **3. Change 1: Number of Neurons**

Earlier, we used:

```id="k8m3zp"
Input (5) → Hidden (8) → Output (1)
```

But we can change it:

* Hidden (4) → simpler model
* Hidden (16) → more powerful model

---

### **4. What Happens When We Change Neurons?**

* **Too few neurons**
  → Model is too simple
  → Cannot learn patterns well

* **Too many neurons**
  → Model becomes complex
  → May memorize instead of learning

👉 Balance is important

---

### **5. Change 2: Learning Rate**

Learning rate controls:

👉 **How big the update steps are**

Example in code:

```python id="r3k9vm"
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

---

### **6. What Happens When We Change Learning Rate?**

* **Very small (0.0001)**
  → Learning is slow
  → Takes many iterations

* **Very large (1.0)**
  → Learning becomes unstable
  → Model may not improve

👉 Ideal value is usually somewhere in between

---

### **7. Real-Life Analogy**

Think of walking to a destination:

* Very small steps → slow progress
* Very large steps → may miss the path

👉 Proper step size → efficient movement

---

### **8. Observing Differences**

When you change parameters:

👉 Always observe:

* Loss decreasing or not
* Accuracy improving or not
* Stability of training

---

### **9. Experiment Example**

Try:

* Hidden neurons = 4, 8, 16
* Learning rate = 0.1, 0.01, 0.001

👉 Compare results

---

### **10. Important Insight**

There is no single “perfect” setting.

👉 You improve the model by:

* Trying
* Observing
* Adjusting

---

### **🎯 Key Idea of This Chapter**

👉 **Improvement comes from experimenting with model settings**
