## **Chapter 10: Why PyTorch?**

---

### **1. The Problem Without Tools**

So far, we have understood everything:

* Neuron calculations
* Forward pass
* Loss calculation
* Backpropagation
* Training loop

Now imagine doing all this **manually**:

* Writing equations for every neuron
* Calculating gradients by hand
* Updating weights step-by-step

👉 This quickly becomes **very complex and time-consuming**

---

### **2. Real-Life Analogy**

Think of doing calculations:

* Without calculator → slow, error-prone
* With calculator → fast and accurate

👉 **PyTorch is like a powerful calculator for neural networks**

---

### **3. What Is PyTorch?**

👉 PyTorch is a library that helps us:

* Build neural networks easily
* Perform calculations automatically
* Train models efficiently

---

### **4. What Does PyTorch Do for Us?**

#### **(1) Handles Calculations Automatically**

Remember this:


$y = w_1x_1 + w_2x_2 + \dots + b$


👉 PyTorch computes this internally
You don’t need to manually calculate anything

---

#### **(2) Automatic Learning (Autograd)**

* PyTorch automatically computes gradients
* No need to do backpropagation math by hand

👉 This feature is called **autograd**

---

#### **(3) Easy Model Building**

Instead of writing complex math:

* You define layers
* PyTorch connects everything

👉 Like building with blocks

---

#### **(4) Efficient Training**

* Handles large data
* Uses CPU/GPU for faster computation

👉 Much faster than manual coding

---

### **5. Simple Comparison**

| Without PyTorch  | With PyTorch           |
| ---------------- | ---------------------- |
| Manual equations | Simple code            |
| Complex math     | Automated calculations |
| Error-prone      | Reliable               |
| Slow             | Fast                   |

---

### **6. Why We Are Using PyTorch in This Tutorial**

Because it allows us to:

* Focus on **understanding concepts**
* Not get stuck in heavy calculations

👉 It helps us move from **theory → practical implementation**

---

### **7. Big Picture**

Instead of worrying about:

* “How to calculate gradients?”
* “How to update weights?”

We can focus on:

👉 “How to design a good model?”

---

### **🎯 Key Idea of This Chapter**

👉 **PyTorch saves effort and handles calculations automatically**
