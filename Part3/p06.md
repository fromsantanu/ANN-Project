## **Chapter 15: Optimizer**

---

### **1. What Is the Role of an Optimizer?**

So far we have:

* Prediction (forward pass)
* Error measurement (loss function)

Now comes the key step:

👉 *“How do we improve the model?”*

The answer:

👉 **Optimizer updates the weights to reduce error**

---

### **2. Simple Idea**

👉 **Optimizer = tool that adjusts weights and bias**

Goal:

* Reduce loss
* Improve predictions

---

### **3. What Is SGD?**

We will use a simple optimizer called:

👉 **Stochastic Gradient Descent (SGD)**

Don’t worry about the name. Let’s understand it simply.

---

### **4. Intuition Behind SGD**

Think of adjusting something step-by-step.

Example:

* You are trying to reach the lowest point in a valley
* You take small steps downward

👉 Each step improves your position

---

### **5. How SGD Works (Simple View)**

1. Model makes prediction
2. Loss is calculated
3. SGD checks **which direction reduces loss**
4. It slightly adjusts weights

👉 Small correction each time

---

### **6. Why “Small Steps”?**

If changes are too big:

* Model may overshoot
* Learning becomes unstable

If changes are small:

* Learning is smooth
* More accurate over time

👉 This step size is called **learning rate**

---

### **7. Writing Optimizer in PyTorch**

Using **PyTorch**:

```python id="k3n9pw"
import torch.optim as optim

optimizer = optim.SGD(model.parameters(), lr=0.01)
```

---

### **8. Understanding This Line**

* `model.parameters()`
  👉 All weights and biases

* `lr=0.01`
  👉 Learning rate (step size)

---

### **9. How Optimizer Is Used**

During training:

```python id="m8v2qx"
optimizer.zero_grad()   # Clear old gradients
loss.backward()         # Compute gradients
optimizer.step()        # Update weights
```

👉 This is where learning actually happens

---

### **10. Real-Life Analogy**

Think of learning to aim at a target 🎯

* You throw → miss
* Adjust slightly
* Throw again → closer

👉 Small adjustments → better accuracy

---

### **11. Key Insight**

* Model does not jump to correct answer
* It improves gradually

👉 **Many small updates = strong model**

---

### **🎯 Key Idea of This Chapter**

👉 **SGD improves the model using small adjustments**
