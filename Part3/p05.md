## **Chapter 14: Loss Function in Code**

---

### **1. From Concept to Code**

Earlier, we learned:

👉 **Loss = how wrong the prediction is**

Now we will implement this idea in code using **PyTorch**

---

### **2. Which Loss Function Are We Using?**

Since our problem is:

* Output → 0 or 1
* Or probability (0 to 1)

👉 We use:

👉 **Binary Cross Entropy Loss (BCELoss)**

---

### **3. Why BCELoss?**

Think of our task:

* Predicting **Yes / No**
* Predicting **Risk / No Risk**

👉 This is called a **binary classification problem**

BCELoss is specially designed for this type of problem.

---

### **4. Intuition Behind BCELoss**

Instead of just measuring difference like:

* (Actual - Predicted)

👉 BCELoss checks:

* *How confident is the prediction?*
* *Is the model strongly right or strongly wrong?*

---

### **5. Simple Understanding**

Let’s say:

#### Case 1:

* Actual = 1
* Predicted = 0.9

👉 Good prediction → low loss

---

#### Case 2:

* Actual = 1
* Predicted = 0.2

👉 Bad prediction → high loss

---

👉 BCELoss **penalizes wrong confident predictions more strongly**

---

### **6. Writing Loss Function in PyTorch**

Very simple:

```python id="8y2djk"
import torch.nn as nn

criterion = nn.BCELoss()
```

👉 `criterion` = the function that measures error

---

### **7. Using the Loss Function**

During training:

```python id="b4k9xm"
loss = criterion(predicted, actual)
```

* `predicted` → model output
* `actual` → true value

👉 This gives a single number (loss)

---

### **8. Connecting to Earlier Concept**

Earlier:

👉 We said loss = error

Now:

* BCELoss = smarter way to measure error
* Works well for probabilities

---

### **9. Important Requirement**

BCELoss expects:

👉 Output between **0 and 1**

That’s why we used:

* `sigmoid()` in the forward function

---

### **10. Big Picture**

Now the flow becomes:

```id="p7m2xr"
Prediction → Loss Function → Error Value
```

---

### **🎯 Key Idea of This Chapter**

👉 **BCELoss measures how wrong probability predictions are**
