## **Chapter 9: Training Process**

---

### **1. What Does “Training” Mean?**

By now, we have all the pieces:

* Neuron
* Network
* Forward pass
* Loss
* Backpropagation

Now we combine everything into one process:

👉 **Training = teaching the model using repeated practice**

---

### **2. The Core Idea**

The model learns through a simple loop:

```id="y9k2pd"
Predict → Calculate Loss → Update
```

👉 This loop runs again and again

---

### **3. Step-by-Step Breakdown**

#### **Step 1: Predict**

* Input data is given
* Model performs forward pass
* Output is generated

👉 Example: Prediction = 0.6

---

#### **Step 2: Calculate Loss**

* Compare prediction with actual value

👉 Example:

* Actual = 1
* Predicted = 0.6

→ There is error

---

#### **Step 3: Update (Learning Step)**

* Backpropagation is used
* Weights and bias are adjusted

👉 Model tries to reduce the error

---

### **4. One Full Cycle**

Let’s visualize one full training step:

1. Input patient data
2. Model predicts risk
3. Compare with actual result
4. Calculate loss
5. Adjust weights

👉 That’s **one iteration**

---

### **5. Repetition Builds Learning**

This process is repeated many times:

* 100 times
* 1000 times
* even more

Each time:

* Errors reduce
* Predictions improve

👉 Just like practice improves skill

---

### **6. Real-Life Analogy**

Think of learning to solve math problems:

* First attempt → many mistakes
* Second attempt → fewer mistakes
* After practice → almost perfect

👉 Repetition leads to mastery

---

### **7. Important Term: Epoch**

When the model sees the **entire dataset once**, it is called:

👉 **One Epoch**

So:

* 10 epochs → model has practiced 10 times
* More epochs → better learning (up to a point)

---

### **8. Visual Flow of Training**

```id="x2k8pw"
[Input Data]
     ↓
[Prediction]
     ↓
[Loss Calculation]
     ↓
[Update Weights]
     ↓
Repeat...
```

---

### **9. Key Insight**

* Learning is **gradual**
* Improvement comes from **continuous correction**

👉 No shortcut — only iteration

---

### **🎯 Key Idea of This Chapter**

👉 **Training = repeating (Predict → Loss → Update)**

This repetition is what makes the model intelligent.
