## **Chapter 7: Measuring Error (Loss Function)**

---

### **1. What Is the Problem Now?**

In the forward pass, the model gives a prediction.

But a very important question is:

👉 *“Is this prediction correct or wrong?”*

We need a way to **measure how far the prediction is from the actual answer**.

---

### **2. What Is Error?**

Error simply means:

👉 **Difference between actual value and predicted value**

* Actual (true answer) → comes from data
* Predicted → comes from the model

---

### **3. Simple Example**

Let’s say:

* Actual risk = **1** (patient is at risk)
* Model predicted = **0.7**

👉 Error = difference between 1 and 0.7

So the model is **close, but not perfect**

---

Another case:

* Actual = 1
* Predicted = 0.2

👉 Now error is large → model is doing poorly

---

### **4. Why Do We Need Error?**

Think like a student:

* If you don’t know your mistakes
* You cannot improve

👉 Same for the model

Without error:

* Model has no idea what is wrong
* No way to improve

---

### **5. Loss Function (Formal Name)**

The method we use to measure error is called:

👉 **Loss Function**

It gives a **single number** representing how bad the prediction is.

---

### **6. A Simple Way to Measure Error**

One common idea is:

\text{Loss} = (\text{Actual} - \text{Predicted})^2

This is called **squared error**.

---

### **7. Example Calculation**

Let’s take:

* Actual = 1
* Predicted = 0.7

Step-by-step:

* Difference = (1 - 0.7 = 0.3)
* Square = (0.3^2 = 0.09)

👉 Loss = **0.09** (small error)

---

Another case:

* Actual = 1

* Predicted = 0.2

* Difference = (0.8)

* Square = (0.64)

👉 Loss = **0.64** (large error)

---

### **8. Intuition**

* Small loss → good prediction
* Large loss → bad prediction

👉 The goal is always:

**Make loss as small as possible**

---

### **9. Real-Life Analogy**

Think of throwing a ball at a target 🎯

* Close to center → small error
* Far away → large error

👉 Loss tells us *how far we missed*

---

### **🎯 Key Idea of This Chapter**

👉 **Loss Function measures how wrong the model is**

This is essential for learning.
